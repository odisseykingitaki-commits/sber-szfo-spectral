**Источник данных: СберИндекс** (расходы муниципальных образований СЗФО, 2023–2024).

Типология **280 муниципалитетов** по структуре расходов.

1. **Презентация** → [`для_жюри/presentation.pdf`](для_жюри/presentation.pdf)
2. **Метод** → [`для_жюри/method_report.pdf`](для_жюри/method_report.pdf) · [текст](для_жюри/method_report.md)
3. **Запуск** → [`INSTALL.md`](INSTALL.md)

Репозиторий: https://github.com/odisseykingitaki-commits/sber-szfo-spectral

## Что открывать жюри

| Папка / файл | Нужно ли открывать | Зачем |
|--------------|--------------------|--------|
| `для_жюри/` | **да, сначала** | презентация и отчёт |
| `configs/` | по желанию | настройки модели (гиперпараметры), проверка воспроизводимости |
| `src/` | по желанию | код расчёта |
| `results/` | по желанию | сохранённые результаты расчётов |
| `data/processed/` | по желанию | готовые признаки и метки |
| `figures/` | **не обязательно** | служебные картинки к отчёту (уже внутри PDF) |
| `scripts/` | нет | сборка PDF/слайдов, служебное |
| `data/raw/` | нет | сырые файлы (локально, см. INSTALL) |
| `docs/` | нет | пустая / служебная |
| `INSTALL.md` | если хотите пересчитать | как запустить пайплайн |

## Короткая карта папок

- `для_жюри/` — презентация и отчёт для жюри
- `configs/` — настройки модели (гиперпараметры), жюри могут проверить воспроизводимость
- `src/` — код
- `results/` — сохранённые результаты расчётов
- `data/` — данные (обработанные в `processed/`)
- `figures/` — служебные картинки к отчёту; открывать не нужно
- `scripts/` — скрипты сборки презентации/PDF (не для просмотра жюри)
