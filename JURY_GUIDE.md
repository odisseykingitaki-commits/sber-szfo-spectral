# Гайд для жюри — спектральная синергетика СЗФО

## За 90 секунд

Представьте карту Северо-Запада: **280 муниципальных образований**, два года расходов СберИндекса (2023–2024). Вопрос не «кто богаче», а **что связывает признаки расходов** — и как эта связь меняется во времени.

Мы сделали два связанных, но самодостаточных шага.

**Проект 1** учит *язык структуры*: из матрицы признаков строим PLM-оператор, смотрим спектр и получаем устойчивую типологию — два равных кластера (140 / 140), которые читаются как «сельский / городской» паттерн расходов. Главное число для запоминания: силуэт **SW ≈ 0.346**, bootstrap ≈ **0.90**, устойчивость по регуляризации ≥ **0.97**.

**Проект 2** берёт этот язык (агрегаты urban/rural + спектральные ряды) и отвечает на прикладные вопросы: *можно ли прогнозировать расходы* и *где ломается структура*. Честный ответ по прогнозу — смешанный: нет одной «победившей» модели, baselines часто рядом с ML. Зато по структурным сдвигам есть ясный консенсус дат: **2023-11, 2024-04, 2024-09**.

Забрать с собой: структура есть и она стабильна; динамика и прогноз — без магии и без раздутых заявлений.

## Как устроены два проекта

Оба проекта живут в **одной вселенной данных**: 280 МО СЗФО, расходы 2023–2024 (плюс мобильность и опционально Trends).

| | Проект 1 | Проект 2 |
|---|----------|----------|
| Роль | язык структуры | применение языка |
| Суть | PLM → спектр J → типология | прогноз расходов + changepoints |
| Главный артефакт | `labels_threshold.npy` (140/140) | `forecast_all_models.csv`, `changepoints_consensus.csv` |

- **Задача 1** — «как устроены признаки»: структура, спектр, типология.
- **Задача 2** — «что с динамикой»: прогноз и точки сдвига. Она *использует* метки и спектральные окна из задачи 1, но **утверждения стоят сами по себе**: baselines (naive / seasonal / mean / Prophet) можно читать, даже если спектральная физика вам не близка.

Жюри может начать с любого проекта. Кросс-ссылки ниже — лёгкие, не обязательные.

## Проект 1. Структура: «что связывает признаки МО»

### Зачем

Обычная кластеризация («KMeans на standardized X») отвечает: *похожи ли объекты*. Нам интереснее другой вопрос: **какие направления в пространстве признаков согласованы**, насколько структура «напряжена» (Frustration), сколько положительных мод (PR₊) — и можно ли из главной моды честно разрезать карту на два типа поведения расходов.

### Что сделали (простыми словами → чуть техники)

1. Собрали матрицу признаков по МО: доли категорий, лог суммы, рост, вариативность, отношение мобильности — **p = 17**, без доходов Росстата.
2. Построили **PLM**-оператор (регуляризация `C_reg = 0.2`) и матрицу **J**, посмотрели спектр: λ_max, **PR₊**, **Frustration**.
3. **Основной метод типологии** — медианный threshold по проекции на главную моду: `U1 = X @ v1`, метка «выше / ниже медианы». Получились два кластера **140 / 140**.
4. **Louvain** — отдельно, для сетевой картины близости в пространстве мод; это не основной результат.  
   Параметры: ε=q₀.₄₀; связные компоненты графа **[278, 1, 1]**; Louvain на *полном* графе → сырые сообщества **[149, 129, 1, 1]**; после merge сообществ размера менее 10 → **[149, 129, 2]** (не «малые компоненты»). CH Louvain ≈ **80.94**.
5. Проверили устойчивость: bootstrap по объектам, перебор `C_reg`, скользящие окна (кто «переключается» между кластерами во времени).

### Главные цифры

Из `results/final_no_income_summary.json` и динамики окон:

| Метрика | Значение | Комментарий |
|---------|----------|-------------|
| SW (threshold) | **≈ 0.346** | качество разреза 140/140 |
| PR₊ | **≈ 3.44** | эффективное число положительных мод |
| Frustration F | **≈ 0.59** | доля «конфликтных» направлений (10/17) |
| Bootstrap ARI | **≈ 0.897** ± 0.07 (n=100) | стабильность меток |
| Robustness (C_reg) | **min ARI ≈ 0.972** (точно 0.97153) | разрез почти не плывёт |
| Перебежчики по окнам | **49 / 277 ≈ 17.7%** | большинство МО держат тип |
| ARI vs KMeans / Louvain | ≈ 0.835 | согласованность, не «доказательство уникальности» |

### Честно про ограничения

- **Без income.** Доходы Росстата не улучшили SW (ablation: no-income 0.346 vs Variant C ≈ 0.345); у СПб нет районной разбивки доходов — честный отказ от признака.
- **«Город / село»** — интерпретация по долям grocery/food, не юридический статус МО.
- **name_norm:** 2 коллизии (`заполярный`, `нарьян-мар`) при внешних join; в основном no-income пайплайне на результат threshold не влияют.
- Bootstrap оптимистичен: scaler на полном N, потом ресемпл строк.
- Мобильность — по сути две даты → `mob_logratio` грубый.

## Проект 2. Динамика: прогноз и сдвиги

### Зачем (даже если Task 1 для вас «просто фичи»)

Структура без времени — красивая карта. Бизнесу и исследователю нужны другие вопросы: **удерживает ли модель расходы на горизонте 1–12 месяцев** и **когда спектр системы дёргается**. Даже если принять кластеры просто как urban/rural-агрегаты, задача 2 остаётся полноценным экспериментом с честным сравнением моделей и консенсусом changepoint-методов.

### Что сделали

1. Агрегировали расходы по меткам threshold: **cluster 0 = сельские**, **cluster 1 = городские**.
2. Прогнали семейство моделей: Naive, Seasonal, Mean, **Prophet**, LightGBM / CatBoost (± Google Trends).
3. **Исправили утечку:** спектральные признаки только из окон с `end_dt < ds` (окно закончилось *до* даты прогноза). Раньше ошибочно `start_dt <= ds` — оттуда фантастические MAE Prophet в старых прогонах.
4. Отдельно — **9 методов** детекции структурных сдвигов по сигналу `[λ₁…λ₅, PR₊]` (без Frustration); дата = конец окна. Консенсус ≥ 50%.

Канон метрик прогноза: **`results/forecast_all_models.csv`**. Черновики `forecast_metrics*.csv` — игнорировать. Разбор: `results/TASK2_NOTES.md`, `results/forecast_mae_post_leakage.md`.

### Главные цифры (после фикса leakage)

**Победители по min MAE** — без «13–22×», без старых артефактов:

| Кластер | H | Победитель | MAE |
|---------|---|------------|-----|
| сельские | 1 | **seasonal** | ≈ 4314 |
| сельские | 3 | **lgbm** | ≈ 1761 |
| сельские | 6 | **naive** | ≈ 1497 |
| сельские | 12 | **prophet** | ≈ 1514 |
| городские | 1 | **prophet** | ≈ 5642 |
| городские | 3 | **prophet** | ≈ 2653 |
| городские | 6 | **prophet** | ≈ 2040 |
| городские | 12 | **naive** | ≈ 2525 |

Картина: Prophet силён на городских (H=1/3/6) и на сельских H=12; на коротких сельских выигрывают seasonal / lgbm; naive не стыдно. **Одной доминирующей модели нет.**

**Changepoint-консенсус** (`changepoints_consensus.csv`):

| Дата | Голоса | Консенсус |
|------|--------|-----------|
| **2024-09-01** | 7 / 9 (≈78%) | да |

| **2024-04-01** | 5 / 9 (≈56%) | да |

### Честно

- Нет модели, которая бьёт всех на всех горизонтах.
- **R² часто < 0** на коротком ряде (24 месяца) — ориентир MAE, не «объяснённая дисперсия».
- Google Trends **не** стабильно помогают (после закрытия leakage часто хуже no-trends).
- **H=12 для LGBM/CatBoost пустой** — мало точек после `lag_12`, ограничение данных.
- Trends мержатся одним агрегатом СЗФО на оба кластера одинаково — грубо.
- Старые MAE Prophet в десятки тысяч — артефакт до пересчёта; в гайде и защите опираемся только на post-leakage таблицу.

## FAQ жюри

**1. Почему основной метод — threshold, а не Louvain?**  
Louvain отвечает на сетевой вопрос («кто с кем в графе близости»). Нам нужна типология по главной моде структуры признаков. Louvain оставлен как согласованный сетевой взгляд (ARI ≈ 0.84 с threshold; SW≈0.348, CH≈80.94), не как канон. Не путать связные компоненты графа [278,1,1] с финальными сообществами [149,129,2].

**2. Почему выбросили доходы?**  
Честный ablation: SW без income ≈ 0.346, с proxy Variant C ≈ 0.345; плюс дыра по районам СПб. Добавлять шумный признак ради «полноты» не стали.

**3. Почему Prophet не «раздавлен» ML?**  
После фикса leakage Prophet нормальный и часто лучший на городских. Старые гигантские MAE — артефакт. На 24 точках сложные модели не обязаны побеждать сезонность и naive.

**4. Что такое Frustration?**  
Доля направлений признаков, которые «конфликтуют» в спектре J (у нас ≈ 0.59 ≈ 10 из 17). Это характеристика *напряжённости* структуры, не ошибка кластеризации.

**5. Задача 2 независима от задачи 1?**  
Почти: использует метки и спектральные окна как входы, но выводы по MAE и changepoints читаются сами. Baselines вообще не требуют верить в PLM — достаточно urban/rural-агрегатов.

**6. Откуда «город / село»?**  
Интерпретация по вкладу долей (grocery ↑ / food ↓ у сельских и наоборот). Это ярлык паттерна расходов, не админстатус.

**7. Почему R² часто отрицательный?**  
Короткий ряд, скользящая оценка, сильная сезонность. Для сравнения моделей смотрите **MAE** и таблицу победителей.

**8. Что с перебежчиками 17.7%?**  
За 19 окон 49 из 277 МО хотя бы раз сменили кластер. Большинство держат тип — структура живая, но не хаотичная (`trajectories.csv`, `fig_dynamic.png`).
