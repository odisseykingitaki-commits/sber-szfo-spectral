## Слайд 3 — KMeans видит похожесть. Мы ищем структуру

**Один и тот же набор данных — два разных вопроса**

- **KMeans:** какие муниципалитеты похожи друг на друга?  
  `17 признаков → расстояния → кластеры`
- **Спектральный подход:** какие направления поведения согласованно проходят через всю систему?  
  `17 признаков → зависимости → J → спектр → главная мода`

**Не просто «кто с кем похож». А «что объединяет систему».**

## Слайд 4 — Как из 17 показателей появляется одна ось

**Мы переводим набор показателей в коллективную структуру**

```
Расходы МО → 17 признаков → PLM → матрица J → спектр мод → главная мода → ось U₁
```

- PLM оценивает, какие признаки связаны между собой
- Спектр показывает наиболее согласованные направления этих зависимостей
- Первая мода становится **главной осью** поведения системы

**λ₁ ≈ 5.541** · **47.1%** положительной спектральной массы

## Слайд 5 — Главная мода на языке экономики

**Что скрывается внутри главной оси?**

Loadings (топ-5): Food **+0.391** · Grocery **−0.374** · Transport **+0.334** · Log total **+0.327** · Health **+0.279**

- Главная мода — не абстракция: это **контраст структуры потребления**
- Полюса: ↑ food · transport · масштаб расходов  ↔  ↑ grocery
- Формулировка для жюри: **два режима структуры потребления** (не юридический «город / село»)
- «Городской / сельский» — лишь мягкая интерпретационная метка паттерна трат

## Слайд 6 — Из оси — два режима

**Мы не задаём кластеры вручную — режем систему по её главной оси**

- Каждый МО получает координату **U₁ = X · v₁**
- Разрез: выше / ниже **медианы** U₁
- Результат by construction: **140 / 140 МО**
- Типология из **главной коллективной моды**, не из заранее выбранных центроидов

Главный визуальный образ: 280 точек вдоль спектральной оси, медиана посередине

## Слайд 7 — Структура выдерживает изменения метода

**Типология не исчезает, если немного изменить настройки анализа**

| Карточка | Число | Смысл |
|----------|------:|-------|
| Bootstrap ARI | **0.897 ± 0.070** | устойчивость к ресемплу объектов |
| Robustness (C_reg) | **≈ 0.972** | min ARI при смене регуляризации PLM |
| Согласованность с baseline | **ARI ≈ 0.835** | близость к KMeans / Louvain — соседние взгляды, не третий идентичный тест |
| Перебежчики во времени | **≈ 18%** | МО, сменившие режим хотя бы раз |

Bootstrap и robustness — прямые проверки устойчивости; ARI к baseline — **согласованность крупномасштабной картины**, не «ещё один такой же тест»

## Слайд 8 — Экономика меняется — но не хаотично

**Структура живая: муниципалитеты могут менять режим**

- Следим не только статическую карту, но и **переходы** между режимами

## Слайд 9 — Что получает аналитик

**Из 17 показателей — в понятную карту экономических режимов**

1. **Сегментация** — 280 МО → два устойчивых режима поведения  
2. **Интерпретация** — режимы из структуры взаимосвязей признаков, не только из похожести строк  
3. **Мониторинг** — кто меняет режим во времени  
4. **Воспроизводимость** — `данные → PLM → спектр → U₁ → типология → динамика`

> Мы не просто нашли два кластера.  
> Мы нашли ось, вдоль которой организована система.
